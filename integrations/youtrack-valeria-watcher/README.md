# YouTrack Valeria Watcher

Отдельное однократное приложение, которое читает YouTrack через удалённый MCP и
запускает заранее созданную таску Valeria при новом упоминании `@Valeria`. Плановый
запуск выполняет systemd timer раз в 10 минут.

## Семантика

- При первом запуске watcher сохраняет текущий момент и не ставит задания по истории.
- Последующие запуски ищут задачи, прокомментированные за последний час, и берут
  только комментарии, созданные за этот час. История большой задачи читается с
  конца, без полного последовательного обхода.
- Если watcher не запускался больше часа, более старые комментарии намеренно
  пропускаются и позже не создают таски.
- Комментарии дедуплицируются по стабильному `focus=Comments-…` из URL.
- Текст комментария в SQLite не сохраняется: хранится только SHA-256.
- Для одной YouTrack-задачи допускается один активный запуск Valeria.
- Новое упоминание во время `queued`, `dispatching`, `running` или `cancelling`
  сразу получает статус `handled_by_active_run`. Новая таска не создаётся ни сразу,
  ни после завершения текущей.
- `completed`, `failed` и `cancelled` — конечные статусы. Следующее новое упоминание
  после них может создать новый запуск.
- Ошибка HTTP до подтверждённого `202 Accepted` сохраняет `submission_retry`.
  Повтор использует тот же `Idempotency-Key: youtrack-comment:<comment-id>`.
- Ошибка выполнения уже принятой таски не вызывает автоматического повтора.

## Доступы

YouTrack MCP читается из `mcp.<YOUTRACK_MCP_NAME>` в OpenCode JSONC. Поддерживаются
обычное значение заголовка `Authorization` и ссылка `{env:VARIABLE}`. Значение
авторизации не записывается в базу или журнал.

Для Valeria нужен отдельный пользователь с рабочей папкой и доступом только к
предварительно созданной опубликованной таске. В `user_input` передаётся только
каноническая ссылка на YouTrack-задачу.

## Локальная проверка

```bash
cd integrations/youtrack-valeria-watcher
uv sync --extra dev
uv run pytest -q
uv run ruff check .
```

## Подготовка установки

1. Создать в Valeria отдельную таску из
   [task-youtrack-comment-response.md](task-youtrack-comment-response.md).
2. Создать пользователя Valeria с режимом «только таски», рабочей папкой и доступом
   к этой таске.
3. Скопировать проект в `/opt/youtrack-valeria-watcher` и установить зависимости в
   `/opt/youtrack-valeria-watcher/.venv`.
4. Скопировать `config.env.example` в `/etc/youtrack-valeria-watcher.env`, заполнить
   значения и установить права `0600 root:root`.
5. Создать `/var/lib/youtrack-valeria-watcher` с правами только для пользователя сервиса.
6. До первого запуска выполнить `youtrack-valeria-watcher-baseline` с переменной
   `WATCHER_DB_PATH`. Команда атомарно записывает текущий момент и при повторном запуске
   не сдвигает его: все более старые комментарии навсегда остаются за baseline.
7. Установить два unit-файла из `deploy/`, выполнить `systemctl daemon-reload` и
   включить timer. Service также выполняет идемпотентный baseline в `ExecStartPre`.

Watcher не требует изменения исходного кода или базы данных Valeria.
