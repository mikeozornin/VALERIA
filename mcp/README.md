# Локальные MCP-серверы

В образ включаются два MCP-сервера, которые использует текущая конфигурация OpenCode:

- `mcp-memory-server` — локальная память;
- `mcp-gitlab-readonly` — GitLab API и Git-операции.

Виртуальные окружения создаются в Docker-образе. База Memory MCP хранится в едином каталоге данных проекта `data/mcp/memory` и не попадает в Git или образ. `config.env` и другие локальные секреты также игнорируются.

Файл `promt` скопирован вместе с MCP, так как OpenCode загружает его по абсолютному пути `/home/appuser/mcp/promt`.
